# Automated Healthcare Document Processing and Intelligence Platform

## Overview

An AI-powered healthcare document intelligence platform for
processing, extracting, classifying, summarizing, and searching
healthcare documents.

## Project Structure

- `backend/` - Backend application
- `frontend/` - Frontend application
- `tests/` - Project tests
- `docs/architecture/` - Architecture documentation
- `docs/api/` - API documentation
- `docs/requirements/` - Requirements and project specifications
